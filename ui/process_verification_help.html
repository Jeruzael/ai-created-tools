How to verify a process

Verification Guide

This report can help you decide what to review, but it does not prove that a program is safe or malicious. Use the steps below to verify a file locally on your PC before making any decision.

Check the digital signature

A digital signature helps confirm who published a file. A valid signature from a known publisher is a good sign, but it does not guarantee the file is safe. An unsigned file is not automatically dangerous, but it deserves more caution.

  1. Find the file path shown in the report.
  2. Right-click the file.
  3. Choose Properties.
  4. Open the Digital Signatures tab if it exists.
  5. Select the signature and click Details.
  6. Check whether Windows says the signature is valid.
  7. Compare the signer or publisher name with what you expected.

Advanced PowerShell option:

Get-AuthenticodeSignature "C:\Path\To\File.exe"
  • Status: Valid means Windows recognizes the signature as valid.
  • Status: NotSigned means the file has no digital signature.
  • Status: UnknownError, HashMismatch, or NotTrusted means the file needs extra review.

Check the SHA-256 hash

SHA-256 is a unique fingerprint of a file. If the file changes, the hash changes. This helps confirm whether a file matches a known official copy.

  1. Copy the file path from the report.
  2. Open PowerShell.
  3. Run the command below.
  4. Copy the SHA256 result.
  5. Compare it with the hash from the official vendor, trusted download page, or internal records.
  6. If the hash does not match, do not assume immediately, but treat the file as suspicious and investigate further.
Get-FileHash "C:\Path\To\File.exe" -Algorithm SHA256

Do not upload private company files, personal files, or unknown executables to public websites unless you understand the privacy risk. Prefer official vendor pages, internal security tools, or local verification first.

What to do next

  • If the signature is valid and the publisher is expected, mark it as reviewed.
  • If the file is unsigned but located in a trusted app folder, inspect it carefully before deciding.
  • If the publisher is unknown, the path looks strange, or the hash does not match the official source, do not delete it immediately. Research it first or ask someone technical.
  • Use official uninstallers, Windows Settings, or vendor tools instead of deleting program files manually.
