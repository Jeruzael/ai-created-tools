Before Reviewing Windows Installer Cache

C:\Windows\Installer is managed by Windows Installer. Cached .msi and .msp files may be required later for repair, update, modify, or uninstall operations.

This dashboard only scans and labels evidence. It does not delete installer cache files, and a probable-orphan result is not a safe-to-delete verdict.

This read-only check compares exact registry paths, reads MSI/MSP metadata, checks installed products and patches, and asks Windows Installer whether an MSP applies to an installed target without launching it. Use it to create a review list, not to clean automatically.

Safe Review Workflow

  1. Use Windows Storage settings and Disk Cleanup first.
  2. Run this read-only cache review.
  3. Export review candidates if any are found.
  4. Review the ProductCode, PatchCode, target ProductCodes, applicability, confidence, and incomplete checks.
  5. Keep a backup outside C:\Windows\Installer before any manual removal.
  6. Confirm Windows Update, app updates, repair, modify, and uninstall operations still work.

Do not delete files from C:\Windows\Installer based only on size, date, or filename.
